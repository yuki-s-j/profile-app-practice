# profile-app-practice

## 概要
COACHTECH 教材 Tutorial 9-1「Laravel基礎ハンズオン」で作成した成果物です。
このセクションで作成した「自己紹介ページ」です。

- PHP 8.x
- Laravel 10.x
- Blade テンプレート

- Bladeテンプレートでの変数表示と@foreachループ
- コントローラーからビューへのデータ受け渡し
